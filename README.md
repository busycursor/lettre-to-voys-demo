# Lettre to Voys: demo

A read-only demo of the Read view: a Middle English manuscript page, read aloud in a reconstructed period pronunciation. Each word lights on the page and in the text as it's spoken, with its gloss, its IPA and where that pronunciation comes from.

- **Manuscript image:** Houghton Library, Harvard University, under these terms: https://nrs.lib.harvard.edu/urn-3:hul.ois:hlviewerterms
- **Pronunciations:** derived by the cited sound rules of Kökeritz, *A Guide to Chaucer's Pronunciation* (1962).
- **Voice:** ElevenLabs `eleven_v4`, from inline IPA.

This is a static snapshot: nothing here runs, voices or edits anything.
